NEXORA FITNESS 10.0 BETA — NEBULA DESIGN PREVIEW

This is a full visual redesign of NEXORA FITNESS. It keeps the existing official NEXORA heart-and-pulse icon, workout engine, local data key (vtaper-pro-v2), saved routines and backup format.

INSTALL
1. Export a JSON backup from your current NEXORA version.
2. Extract this archive into a new folder.
3. Open NEXORA-FITNESS/index.html in Chrome.
4. Use the existing backup import control to preview and restore your JSON backup.
5. Keep your previous folder until you confirm your workout history and routines transferred correctly.

DESIGN
- New Nebula visual system across Today, Train, Progress, Browse, History, Planner, Insights, Guide and Settings.
- Existing fixed bottom navigation, sticky top header and More menu retained.
- Light, dark and follow-device appearance are supported.
- The official NEXORA logo is unchanged.

OFFLINE / PWA
For service-worker caching and PWA installation, host the folder through HTTPS or localhost. Opening index.html via file:// still allows local app use but does not enable service workers.
